Riscos
ALTO

iOS / Safari — botão de galeria do sistema

O Safari no iOS exibe um botão que permite trocar para a galeria. Esse botão é renderizado pelo sistema operacional e não pode ser removido por uma PWA. Se iPhones forem obrigatórios em campo, avaliar Capacitor como solução nativa.

MÉDIO

HTTPS obrigatório

A API getUserMedia só funciona em localhost ou origens HTTPS.

MÉDIO

Permissão de câmera negada

Se o auditor negar a permissão, o app recebe NotAllowedError e precisa exibir mensagem clara com instrução para habilitar nas configurações.

BAIXO

Qualidade da imagem via canvas

A resolução depende da câmera do dispositivo e das constraints do getUserMedia. Validar se a qualidade é suficiente para identificação de não conformidades.
