POC 4 — Comparativo input capture

input type="file" capture="environment" — rejeitado

O atributo capture é apenas uma dica para o sistema operacional, não uma restrição. O SO pode ignorá-lo e abrir o seletor de arquivos com acesso à galeria. Não há como forçar câmera exclusiva via HTML.

getUserMedia + canvas — adotado

Abre o stream da câmera diretamente dentro do app. Nenhum seletor do sistema operacional é invocado. O auditor não vê opção de galeria porque ela não existe nesse fluxo.

Demo — input capture

Clique no botão abaixo e observe se o sistema oferece opção de galeria além da câmera.

<input type="file" accept="image/*" capture="environment">

  • Android Chrome: exibe seletor com câmera e galeria
  • iOS Safari: menu com câmera, biblioteca de fotos e arquivos
  • Desktop: abre o explorador de arquivos, sem câmera
